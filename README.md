## 👨‍💻 About Me

By day, I'm a Software Engineer at SEL. By night, I build open-source tools for the AI research community and develop agritech solutions to empower the sustainable agriculture marketplace in Vietnam.

## 🚀 What I'm Working On

**🌾 AgriTech Marketplace** - Building a platform that empowers small-scale farmers with direct market access and supply chain traceability, creating transparency and trust in local food systems.

**🤖 Agent Capabilities & Safety** – Expanding what AI agents can do through custom tool interface protocols, while simultaneously hardening them against vulnerabilities using entropy-based security probes.

**⚡ Power Systems Test Automation** - Architecting IEC 61850 test automation infrastructure for critical power grid protection and control systems, ensuring reliability at scale.
